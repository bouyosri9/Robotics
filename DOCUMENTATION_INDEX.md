## 🎓 Key Concepts

### Terminology

**Cobot** - Collaborative Robot
- Designed for human-robot interaction
- Safety features built-in
- Various payload and reach capabilities

**Forward Kinematics**
- Calculating TCP position from joint angles
- Used for visualization and verification
- Mathematical model in [ARCHITECTURE.md](ARCHITECTURE.md#kinematics-model)

**TCP (Tool Center Point)**
- Position of robot's tool/end-effector
- Calculated in 3D space (x, y, z)
- Updated in real-time via kinematics

**Joint Angles**
- Rotation angles for each arm segment (J1-J6)
- Measured in degrees
- Each joint has physical limits

**State**
- Current robot configuration
- Includes: joint angles, target, status, TCP, timestamp
- Broadcast via WebSocket 20 times/second

### Component Breakdown

**Frontend**
- React 19 application
- Three.js for 3D visualization
- Vite build tool
- Runs on port 8090

**Backend**
- Express.js server
- WebSocket for real-time communication
- REST API for stateless operations
- Simulation engine with kinematics
- Runs on port 4000

**Infrastructure**
- Docker containers for isolation
- Docker Compose for orchestration
- Prometheus + Grafana for monitoring
- Nginx as reverse proxy
